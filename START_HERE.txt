IN A PINCH V4 — U.S. RESTROOM ATLAS

OPEN THE MAP
Extract the entire ZIP and double-click OPEN_ME.html. Keep the data and
assets folders beside it. The national directory is included in the download.
Street tiles, external maps and neighborhood updates use the internet.

FIND A STOP
Choose “Find near me,” pan the map or use “Browse destinations” to jump
to a state, territory or city. Select a numbered group and zoom in for
individual stops. Select a stop to see its source and directions.

ON THE ROAD
Select “Gas & rest stops” for roadside places. Add “Showers” to show only
those with documented showers. The listing gives the count when the source
provides one. Check current availability, hours and fees with the operator.

UPLOAD TO GITHUB PAGES
Keep index.html and all accompanying files and folders together. Place the
contents of IN_A_PINCH_V4_GITHUB_UPLOAD in your Pages publishing directory.
To keep earlier editions at their current URLs, put this site in v4/.

For a local preview with browser location access, run
python3 -m http.server 8080
from this folder and open http://localhost:8080. The hosted map works on
HTTPS. No map API key is needed. Shared ratings use the optional backend.

See README.md for coverage, source dates and publishing details.
